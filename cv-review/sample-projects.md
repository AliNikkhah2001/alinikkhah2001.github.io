> **Please read:** these are illustrative write-up templates showing how project work is documented — scope, deliverables, proof. They are not employment claims. Verify every number against dashboards, logs, or letters before using any line anywhere.

## How to use a sample

1. Pick the template matching the role.
2. Replace each bracketed item with your verified artifact.
3. Keep one metric per bullet, each traceable to proof.

## ML Engineer — Graph RAG Assistant (sample)

- Scope: domain assistant over a knowledge graph + vector index, [N] analysts.
- Deliverables: schema-aware Cypher tool-calls; citation-enforced answers; deterministic fallback; GPU runtime profile (KV-cache, batching, quantization) with [latency/memory] deltas.
- Proof: [architecture diagram], [benchmark sheet], [eval report].

## Senior Data Scientist & Data Engineer (sample)

- Scope: lakehouse + risk + conversational support for retail operations.
- Deliverables: CDC pipeline ([volume]/day, [freshness]); risk ensemble ([AUC], [default-rate delta]); voice chatbot ([ticket delta], [intent accuracy]); allocation engine ([risk-adjusted return delta]).
- Proof: [pipeline diagram], [model card], [A/B readout].
