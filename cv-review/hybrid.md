The 1-page is the only true one-pager alongside Senior and Platform — best for portals with hard page limits. The 2-page file currently overflows to 3 pages; trim oldest bullets first when a strict 2-page cap applies.

## Market fit

Strongest proof: breadth with depth in three systems (marketplace RAG, edge CV, BNPL risk). Attach one artifact per pillar. Best default variant when the posting mixes ML, data, and deployment.

## 1-page vs 2-page

Default to the true 1-page for online applications; use the 2-page file for hiring-manager forwards after trimming to two pages.
