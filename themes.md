# Site Theme

This site uses a single, hand-crafted **"Code Editor" theme** — a professional,
classic programming aesthetic with terminal accents:

- **Typography** — clean system sans-serif for body text, monospace for code, prompts, and meta labels
- **Structure** — section titles rendered as `## comments`, the hero framed like a code file, and the experience timeline drawn in a git-log style
- **Accents** — a restrained blue accent, editor light-canvas background, inline `code` chip styling for skills

The previous multi-theme switcher has been removed in favour of one consistent,
responsive design. Styles live in `assets/css/style.css`.
